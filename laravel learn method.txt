Checkbox sends multiple values.

11. implode() (Key Concept)
📌 What it does
Converts array → string
📌 Example
implode(',', ['SSLC', 'HSC'])
Output:
SSLC,HSC
Used before inserting into DB.

12. explode() (Reverse of implode)
📌 What it does
Converts string → array
📌 Example
explode(',', 'SSLC,HSC')
Output:
['SSLC', 'HSC']
Used while editing to check checkboxes.

eg :insert and edit checkboxes
<input type="checkbox" name="qualification[]" value="10th"
{{ (isset($editData) && in_array('10th', explode(',', $editData->qualification))) ? 'checked' : '' }}>
10th

Checkbox → multiple selection

qualification[] → array input

explode() → string to array

in_array() → value exists or not
eg: in_array('10th', array)

Checks:
👉 “Is 10th present in this array?”
Result:
Yes → true
No → false
checked → selects checkbox automatically

----OPERATORS----
1. ?? → Null coalescing operator Used to give a default value when something is NULL or not set
eg:$value = $a ?? $b;
Meaning:
If $a exists and is NOT null → use $a
Else → use $b
---Real-Time Laravel Example for this operator (Insert & Edit Form)
value="{{ $editData->name ?? '' }}"

What happens?
Situation	          Result
Insert (no data)	-Empty input
Edit (data exists)	-Shows existing name

2. Ternary operator ? : Used to write short if–else condition 
in one line(condition ? value_if_true : value_if_false;)
----Real-Time Laravel Example for this operator (Edit Form)
<button>
{{ isset($editData) ? 'Update' : 'Submit' }}
</button>
Meaning:
Condition	 Button Text
Edit mode	   Update
Insert mode	   Submit

-----edit and update logical work-----
index() – READ + EDIT (2 jobs)
✅ Job 1: Get all records
$data = DB::table('login_table')->get();

➡️ Used to show the table data.

✅ Job 2: Prepare edit data
$editData = null;

➡️ If not editing → form stays empty.

✅ Check edit request
if ($request->has('edit')) {

When user clicks:

<a href="/example?edit=5">Edit</a>

URL becomes:

/example?edit=5

Laravel gets:

$request->edit = 5;

✅ Fetch one record
$editData = DB::table('login_table')
              ->where('id', $request->edit)
              ->first();

➡️ Gets only one row for editing.

✅ Send to view
return view('example', compact('data', 'editData'));

Blade can:

Show table → $data

Auto-fill form → $editData

✏️ EDIT (Frontend logic)

Edit link:

<a href="{{ route('student.index', ['edit' => $row->id]) }}">Edit</a>

Flow:

Click Edit → index() → fetch row → form auto-filled

Auto-fill example:

<input type="text" name="name" value="{{ $editData->name ?? '' }}">

🔄 update() – UPDATE record
How Laravel knows UPDATE?

Form action:

action="{{ route('student.update', $editData->id) }}"

URL:

/student/update/5

Laravel gets:

$id = 5;

Update code
DB::table('login_table')
  ->where('id', $id)
  ->update([
      'name' => $request->name,
      'email' => $request->email,
      'qualification' => implode(',', $request->qualification),
      'updated_at' => now()
  ]);

Simple meaning:

“Update only the row where id = 5”

⭐ Important rule
Without where	With where
❌ Updates all rows	✅ Updates one row
updated_at
'updated_at' => now();

➡️ Saves last modified time.

🧠 ONE-LINE MEMORY
index() = show + prepare edit  
edit = fetch one row  
update() = where(id) → update
